# Dérive & Drift

Interactive phone prototype of a Paris wandering guide. Live at https://derive-drift.netlify.app (Netlify site `derive-drift`).

- Single static page: `index.html` (no build step). Photos in `img/`.
- Useful links: `?intro=1` always shows onboarding, `?rain=1` starts in rainy weather, `?mode=derive` opens the reading view.
- To redeploy, publish this folder as the site root.
